Every song, sung by a villager.

Hrrmony (the villager’s “hrmm” plus harmony) pulls the vocal out of any track, re-sings it in the voice of a Minecraft villager and lays it back over the original music. It runs on your own machine, so your music never leaves it.

Features

Four things it does well.

One job, done locally: turn a song you love into the villager cover everyone keeps asking for.

01 Default mode

Hook mode / --hook

Best 30 seconds

Drop in a song and it finds the chorus for you: the loudest stretch whose harmony repeats most, snapped to a beat. Or pick your own start with --start.

  • Auto chorus
  • Beat-snapped
  • ~25 s on an RTX 4050
02 One flag

Full mode / --full

The whole song

Every verse, every chorus, every ad-lib, re-sung by a villager over the untouched instrumental. A three-minute track takes about a minute on a laptop GPU, and it still works on CPU.

  • Original instrumental
  • MP3 and WAV
  • Stems on request
03 hrrmony serve

Web app / CLI / Python

Upload, listen, download

A local web app with live progress and side-by-side playback of the cover and the original. Prefer the terminal? One command does the same, and make_cover() does it from Python.

  • Live progress
  • A/B playback
  • Docker image
04 Open research

Measured / not guessed

Matched to the viral sound

We took a popular AI villager cover apart: pitch, syllables, noise bursts, EQ and level. Hrrmony reproduces it, and every number is in the repository.

  • −8 semitones
  • Dry, mono, −3.9 dB
  • Research log

Install / Python 3.10 to 3.12

Three commands to your first cover.

You need ffmpeg on your machine. The first cover downloads about 1.2 GB of models, then everything runs offline.

  1. Install

    pip install "hrrmony[gpu,web] @ git+https://github.com/kenny2077/hrrmony"

    No NVIDIA GPU? Use [cpu,web] instead.

  2. Check

    hrrmony doctor

    Confirms ffmpeg, your GPU and the model cache.

  3. Cover

    hrrmony cover song.mp3        # best 30 s
hrrmony cover song.mp3 --full # whole song
hrrmony serve                 # web app

    Covers land next to you as MP3 and WAV, with the original excerpt for comparison.
